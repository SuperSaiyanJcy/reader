## Reader v1.1.2

Word 风格的本地 TXT 阅读器，现已开源。

### 功能

- 连续纸张排版，章节和卷标题直接衔接前文，去掉页尾大块补白。
- 左侧“导航”按钮一键开关目录，支持预设规则与自定义正则预览。
- 四个方向键按屏翻读，保留两行原文，支持滚轮与空格翻读。
- 字体、字号、行距、颜色、缩进与对齐设置；支持本地 TTF 导入和重启恢复。
- 全文查找、最近阅读、自动续读与工作文档快速切换。

### 本版完善

完整中文 README、界面截图、贡献指南、许可证说明和双平台自动构建发布。改进文末排版的自动化测试定位，使用真实导航操作验证连续排版。

### 下载

| 平台 | 文件 |
| --- | --- |
| macOS 13+ / Apple Silicon | `Reader-1.1.2-mac-arm64.dmg` 或 `.zip` |
| Windows 10/11 x64 | `Reader-1.1.2-win-x64.exe` 或 `.zip` |

Windows ZIP 需要完整解压后运行其中的 `Reader.exe`。macOS 使用 ad-hoc 签名，未做 Apple 公证；Windows 未使用商业发行证书签名。

**文件 → 打开**选择 TXT，**开始**调整排版，左侧**导航**打开目录。Esc 显示工作文档，Ctrl / Command + Shift + R 恢复阅读。

附带 `SHA256SUMS.txt` 可校验下载文件。源码与详细说明见仓库 README。
