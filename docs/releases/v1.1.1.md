## Reader v1.1.1

Word 风格的本地 TXT 阅读器，支持 Apple Silicon macOS 与 Windows x64。

### 本版改进

- 连续纸张排版，去掉页尾大块补白和内部页间空白。
- 新章、新卷直接衔接前文，不强制换页。
- 左侧“导航”按钮一键开关目录。
- 方向键按屏翻读，保留两行原文方便衔接。
- 支持本地 TTF 字体导入、去重和重启恢复。

### 下载与使用

- **macOS 13+ / Apple Silicon**：下载 `Reader-1.1.1-mac-arm64.dmg`，拖入“应用程序”。
- **Windows 10/11 x64**：下载安装器 EXE，或完整解压 `Reader-1.1.1-win-x64.zip` 后运行 `Reader.exe`。
- 文件 → 打开选择 TXT；开始设置字体；左侧导航查看目录。
- Esc 切换工作文档，Ctrl / Command + Shift + R 恢复阅读。

macOS 使用本地 ad-hoc 签名，未做 Apple 公证；Windows 未做发行证书签名。请按系统提示允许打开，并从本仓库下载。

源码、详细说明和已知边界见仓库 README。附带的 `SHA256SUMS.txt` 可用于校验下载文件。
